# 对外设备接口文档

## 一、通用约定

| 项       | 约定                                                                                                                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 方法     | **仅 POST**                                                                                                                                                                              |
| 验证     | **免验证**：                                                                                                                                                                             |
| 报文     | JSON`Content-Type: application/json`                                                                                                                                                         |
| 响应壳   | `{"code": <int>, "message": <str>, "data": ...}`，**code 与 HTTP 状态一致**                                                                                                            |
| 错误消息 | **中文**                                                                                                                                                                                 |
| 公司     | 报文必含**`M_DATA_AUTH`**（组织机构标识）→ 按 `res.company` 的**公司注册号**（company_registry）精确匹配；**例外**：AOI 用 `machineName`（工作中心编码）→ 工作中心归属公司 |
| 日志     | 每次调用全量落「设备API日志」（ Manufacturing → 追溯性 → Device API Logs），密码字段脱敏存储                                                                                                 |

### 错误状态码分级

| code/HTTP  | 含义         | 典型                                                     |
| ---------- | ------------ | -------------------------------------------------------- |
| 200 / 201* | 成功         | *AOI 成功为 HTTP 201 + body code 200（契约冻结）         |
| 400        | 报文结构问题 | 非法 JSON、缺必填字段、字段类型/格式非法                 |
| 401        | 认证失败     | auth/check 账号或密码错误                                |
| 403        | 越权         | auth/check 用户不属于该组织                              |
| 404        | 资源不存在   | 组织未知、制造订单/工作中心/员工/缺陷码不存在            |
| 422        | 业务规则拒绝 | quantity 值域、结果非 OK/NG、NG 无确认不良、无在线制令单 |
| 500        | 系统错误     | 未预期异常                                               |

### 部署前置

- 各公司在 **设置 → 公司 → 常规信息 → 公司注册号** 维护对外组织码（设备发什么就配什么；未配置 = 全部业务接口报"组织机构不存在"）。

## 三、接口明细

`M_DATA_AUTH = zone`

### 1. 过站上报 `POST /api/v1/workorders/scan-pass`

设备软件一次上报完成过站全链路：身份解析（含铭牌/拼版扇出）、过站内核、测试结果落库、组件/铭牌绑定、包装、SMT 扣点。

**请求**（主字段，全量字段以宽表镜像为准）：

```json
{
  "M_DATA_AUTH": "1",
  "M_SN": "SN0001",
  "M_WORK_STATIONSN": "WC001",
  "M_EMP": "OP001",
  "M_TEST_RESULT": "OK",
  "M_STR2": "",
  "M_TEST_DETAIL": [{"item_name": "Voltage", "low_limit": "0", "up_limit": "10", "item_value": "5", "item_result": "OK"}],
  "external_event_id": "evt-001"
}
```

| 字段                                    | 必填    | 说明                                        |
| --------------------------------------- | ------- | ------------------------------------------- |
| M_DATA_AUTH                             | 是      | 组织机构标识                                |
| M_SN                                    | 是      | 产品 SN（可为铭牌码，自动解析整机 SN）      |
| M_WORK_STATIONSN                        | 是      | 工作中心编码                                |
| M_EMP                                   | 是      | 操作员工号（barcode 或登录名）              |
| M_TEST_RESULT                           | 是      | OK / NG                                     |
| M_STR2                                  | NG 必填 | 缺陷码（按码或名匹配字典）                  |
| M_TEST_DETAIL                           | 否      | 测试项明细数组（项目/上下限/实测/单项结果） |
| M_MAIN_ID / M_MODULE_ID / M_LEADSEAL_ID | 否      | 组件码（组装台账，二次组装拦截）            |
| M_BOX_SN / M_SECOND_SN / M_PACK_*       | 否      | 包装（NG 禁包装、容器须新）                 |
| M_PARAMETER_PLAN 等 4 个工艺文件编号    | 否      | 传入即校验（须在 MO 对应工序维护清单内）    |
| external_event_id                       | 否      | 幂等键                                      |

**响应**：`200 {"code":200,"message":"OK","data":{"ok":true,"sn":"SN0001","panel_qty":4,"finished":false,"test_result_id":123}}`

**规则**：NG 走维修闭环（工序 NG 上限 → 达上限送维修，维修关单计数重置）；SMT 制令单扫拼版任一板 → 全板扇出过站（扫中板带结果、其余按 OK）；同 external_event_id 重报幂等返回。

### 2. 领号 `POST /api/v1/next-sn`

```json
请求:  {"M_DATA_AUTH": "1", "M_WORK_STATIONSN": "WC001"}
响应:  200 {"code":200,"message":"OK","data":{"ok":true,"sn":"DWG-A01000042","mes_order":"MO-001"}}
```

按工作中心 → 产线**在线制令单**发下一个未用 SN（图号前缀+5 位流水，产品级共享序列，永不重复）。

### 3. 镭雕批量领号 `POST /api/v1/laser/print-requests`

**请求**：

```json
{
  "M_DATA_AUTH": "1",
  "workOrderNo": "WH/MO/09045",
  "quantity": 8,
  "panelQty": 4,
  "drawingNo": "DWG-2026-A01",
  "operator": "OP001"
}
```

| 字段        | 必填 | 说明                                                                                                  |
| ----------- | ---- | ----------------------------------------------------------------------------------------------------- |
| M_DATA_AUTH | 是   | 组织机构标识                                                                                          |
| workOrderNo | 是   | **制造订单号**（mrp.production 单号，ilike 匹配；输制令单号会 404）                             |
| quantity    | 是   | 正整数，≤10000                                                                                       |
| panelQty    | 否   | 拼版数量（每拼版板数）；提供则按生成顺序自动切拼版，**尾板不齐照常建不满拼版**（10/4 → 4+4+2） |
| drawingNo   | 否   | 留痕不校验                                                                                            |
| operator    | 是   | 操作员工号（在册校验）                                                                                |

**响应**：`200 {"code":200,"message":"OK","data":{"productSnList":["DWG-A0100001",...],"quantity":8,"panelQty":4}}`

**规则**：SN 挂制造订单（打码先于制令单上线，无在线要求）；与页面【生成SN】/next-sn 同一序列，跨单永不重复；自动拼版与 `/api/v1/panels/add` 同一创建内核，建好即对过站扇出生效；拼版总量受 MO 计划量约束（超排产 422）。

### 4. AOI 上报 `POST /api/v1/aoi/results`

**契约冻结**（设备已对接，字段不可增删改名；成功 **HTTP 201** + `message:"success"`；缺字段错误为英文 `Missing required field: <field>`）。

**请求**：

```json
{
  "productSn": "M0022S012623487760",
  "machineName": "WC-AOI-01",
  "retestResult": "失数",
  "stationResult": "OK",
  "stationInfo": "OK:过站成功 当前工序[DIP-AOI工序]已过站数量[2040]",
  "testTime": "2026-06-10T17:13:08",
  "createTime": "2026-06-10T17:13:08",
  "operator": "2504",
  "defectDetails": [
    {"partId": "R101", "position": "X=12.5,Y=34.2", "defectCode": "LCAO1-3",
     "defectName": "反件", "confirmedResult": "确认不良", "imagePath": "/aoi/images/x.jpg"}
  ]
}
```

| 字段                                                                                                    | 必填         | 说明                                                                                    |
| ------------------------------------------------------------------------------------------------------- | ------------ | --------------------------------------------------------------------------------------- |
| productSn / machineName / retestResult / stationResult / stationInfo / testTime / createTime / operator | 是           | machineName =**工作中心编码**（公司取工作中心归属，无 M_DATA_AUTH——已记录例外） |
| stationResult                                                                                           | —           | 只认 OK / NG；retestResult/type 等仅留痕                                                |
| defectDetails[].defectCode / defectName / confirmedResult                                               | 是（明细内） | 明细 verbatim 落库不校验字典                                                            |
| logCode                                                                                                 | 否           | 幂等键（缺省`aoi:{machineName}:{productSn}:{testTime}`），重报返回成功不二次过站      |

**响应**：成功 `HTTP 201 {"code":200,"message":"success","data":{}}`。

**规则**：一次上报 = AOI 测试结果（test_type=aoi，测试结果菜单可查，表单带"AOI Defects"明细页签）+ 过站（含拼版扇出，与 scan-pass 同内核）；NG 主码 = 第一条 `confirmedResult=确认不良` 明细的 defectCode 查字典（无确认不良或字典无命中 → 422）；明细另见追溯性 → AOI Defect Details 菜单。

### 5. 登录校验 `POST /api/v1/auth/check`

```json
请求:  {"M_DATA_AUTH": "1", "userName": "op_zhao", "password": "Op@2026!"}
响应:  200 {"code":200,"message":"OK","data":{"userName":"op_zhao","employeeName":"赵工"}}

探活:  {"M_DATA_AUTH": "1"}  →  200 {"code":200,"message":"OK","data":{}}
错误:  401 "账号或密码错误。" / 403 "账号 x 不属于该组织机构。" / 404 "员工 x 在 MES 中不存在。" / 400 缺字段
```

对 Odoo 账号真实密码认证；登录名须挂 hr.employee 员工档案（与过站同一套规则——能登录就能过站）；**密码在接口日志中脱敏为 `***`**；不带 userName/password = 纯探活。

### 6/7. 拼版 `POST /api/v1/panels/add` / `POST /api/v1/panels/query`

```json
新增:  {"M_DATA_AUTH": "1", "productNo": "WH/MO/09045", "quantity": 4, "pcbItemSn": "",
        "bindings": [{"boardNo": "1", "proSn": "SN001"}, {"boardNo": "2", "proSn": "SN002"}]}
       → 200 {"code":200,"message":"OK","data":...}
查询:  {"M_DATA_AUTH": "1", "proSn": "SN002"}          // 任一板 SN
       → 200 {"data": {"panels": [...], "total": 1}}   // productNo 查询亦可
```

人工通道（补录/特殊场景）；镭雕端点 panelQty 是它的自动化版，两者同内核并存。板 SN 须为已存在 identity（限公司）。

### 8. 制令单查询 `POST /api/v1/manufacturing-orders/by-work-order`

**契约冻结**（字段名/返回结构按设备文档；message 固定 `success`）。

```json
请求:  {"M_DATA_AUTH": "1", "work_order": "WH/MO/08321"}
响应:  200 {"code":200,"message":"success","data":["WH/MO/08321-2","WH/MO/08321-1"]}
```

`work_order` 对**制造订单号** ilike 匹配，返回其未取消**制令单号一维数组**（id 倒序，全量）；无命中 `data: []`；缺 work_order 400。

### 9. 工作中心搜索 `POST /api/v1/work-centers/search`

```json
请求:  {"M_DATA_AUTH": "1", "work_station": "SMT"}     // 空/缺省 = 全量
响应:  200 {"code":200,"message":"success","data":[["WC001","SMT贴片线1"],["WC002","SMT贴片线2"]]}
```

`work_station` 对 code/name ilike；二维数组 `[编码, 名称]`，code 升序，全量无上限。

### 10. 不良代码搜索 `POST /api/v1/defect-codes/search`

```json
请求:  {"M_DATA_AUTH": "1", "err_name": "短路"}        // 空/缺省 = 全量
响应:  200 {"code":200,"message":"success","data":[["DC001","锡珠短路"],["DC002","桥接短路"]]}
```

`err_name` 对 code/name ilike；二维数组 `[不良代码, 不良名称]`，code 升序，全量无上限。

### 11/12. 波峰焊/回流焊温区 `POST /api/device/wave` / `POST /api/device/reflow`

```json
请求:  {"device_sn": "WAVE-01", "collect_time": "2026-09-09T10:00:00",
        "zones": {"Z1": 245.5, "Z2": 250.0}}
响应:  200 {"code":200,"message":"Saved successfully"} / 400 英文原因
```

温区采集包入库（zone 名→温度映射，ISO8601 时间），两条路由同一内核；无 M_DATA_AUTH（设备采集类）。

## 四、相关页面

- **设备API日志**：Manufacturing → 追溯性 → Device API Logs（全量原文+响应+耗时，密码脱敏）
- **测试结果**（含 AOI）：Manufacturing → 追溯性 → Test Results（分屏，AOI 记录带缺陷明细页签）
- **AOI 缺陷明细**：Manufacturing → 追溯性 → AOI Defect Details
- **SN 追溯四宫格**：Manufacturing → 追溯性 → SN Trace
