# List Column Width Saver

## Overview

Persistent List Column Widths keeps user-resized width in Odoo list/tree views and restores them after refresh.

## Features

- Persists manual column widths per user.
- Scope isolation by database + user + list view definition.
- Automatic restore only when the current column layout matches.
- Reset action clears saved widths for the current view.

## Compatibility

- Backend web client list/tree views

## Installation

1. Place module in addons path.
2. Update apps list.
3. Install `List Column Width Saver`.
